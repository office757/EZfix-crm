# Content campaigns and reference calendar

Campaign Manager is now a saved organic-content workflow, available from Social Media for owner/office users and from the Marketing Manager dashboard for that role. Existing paid-ad campaign/attribution tables are unchanged. New content campaigns keep a brief and platform, generate successive series using the existing text/image service, save each completed draft and resume incomplete generations. Content can be edited and scheduled, office staff approve individual revisions, and approved posts become due for publishing. A fifteen-minute cron creates one in-app owner/office notification per approved revision. Manual publication requires confirmation and the HTTPS link to the live post. External social account publishing is not connected.

Marketing accounts access only their own content campaigns and attached generated images; invoice, payroll, owner settings and private customer/gallery storage permissions are unchanged. Marketing staff cannot approve their own drafts. Editing approved content resets its approval, stale revisions are rejected, and published content is retained as history. Repeated identical save requests return the existing draft rather than creating duplicate posts. Generated image links are renewed when campaigns load. Owner generation is exempt from the existing staff hourly allowance.

The monthly calendar has been structurally rebuilt to follow the supplied reference, rather than only recolored: navy canvas, glossy blue/navy/yellow counters, centered month navigation inside the white panel, the actual number of weeks in each month, compact time/service chips and selected-day cards beneath the month. Selected-day cards show real technician initials, status, work, customer, address and contact controls; no stock technician portraits or fabricated live counters are used. Mobile shows calendar dots, stacked job cards, the original logo, dark bottom navigation and a yellow job-add button. Existing role/technician filters, preview/contact actions, selected-day state and weekly appointment geometry remain available. Month changes keep the selected date within the visible month. The logo image file remains byte-identical.

Verification includes release gates, controlled AI writer authorization checks, and rolled-back database tests for draft/approval/publication transitions, stale revision rejection, reminder deduplication, campaign ownership and marketing financial isolation. Browser visual verification could not be completed: automatic approval review rejected temporary access to the protected preview. Calendar behavior is tested against the actual renderer; no signed-in visual verification is claimed. Temporary design-check pages are removed before production merge.
